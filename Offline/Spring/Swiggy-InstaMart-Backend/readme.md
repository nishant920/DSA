# Swiggy InstaMart MVP

A Minimum Viable Product (MVP) for Swiggy InstaMart that simulates a hyperlocal grocery delivery system. The platform includes different roles with distinct capabilities such as shoppers, warehouse admins, delivery partners, and app administrators.

---

## 🚀 Features

### 🛒 Shoppers
- View products available in their **pincode-specific warehouse**.
- Add and remove products from their **shopping cart**.
- **Place orders** from available inventory.
- Select and **switch between locations** (pincodes).
- Choose from **multiple payment methods**.

---

### 🏬 Warehouse Admin
- **Request new products** required in their warehouse.
- **Approve registration requests** from delivery partners.

---

### 🚴 Delivery Partners
- **Mark themselves available or unavailable** for deliveries.
- **Update delivery status** (e.g., Delivered, In-Progress).

---

### 👨‍💼 App Admin
- **View warehouse-wise order analytics**.
- **Review and approve** product requests raised by warehouse admins.

---

## 🛠 Tech Stack (Suggestive)
- **Backend**: Spring Boot / Node.js / Django
- **Frontend**: React / Angular / Vue.js
- **Database**: PostgreSQL / MongoDB
- **Authentication**: JWT / OAuth2
- **Deployment**: Docker, Koyeb, Vercel, or Render
